# Планета знаний — мини-приложение, прототип v1

Визуальный стиль согласованных карточек, оригинальный логотип из предоставленного файла, настоящее фото «Островка». Данные извлечены из утверждённой базы знаний от 20.11.2026, без изменений действующих Telegram/MAX ботов.

## Проверка

Распакуйте архив. В папке проекта запустите `python -m http.server 8000` и откройте http://localhost:8000. Для телефона разместите папку на HTTPS-хостинге.

## Что уже работает

Навигация, возрастной подбор, каталог, поиск, подробные страницы, расписание по направлениям, специалисты, праздники, «Островок» с реальным фото, контакты и кнопки связи.

## Что пока НЕ реализовано

- Запись как отправка заявки внутри бота: кнопка открывает контакт администратора, не отправляет форму и не подтверждает запись.
- Отзывы: пустой раздел до получения реальных отзывов.
- Авторизация Telegram Mini App / MAX и серверная интеграция.
- Обновление данных автоматически из GitHub: пока статический `data.json`.
- Иллюстрации отдельных карточек: сейчас стилизованные кнопки и одна новая иллюстрация для главной.

## Важно

Не публикуйте токены ботов в HTML/JS. Не меняйте main.py/max_main.py без проверки текущего способа запуска. При обновлении расписания/цен синхронизируйте `data.json` с утверждённой базой. Срок актуальности: 20.11.2026.
